# Autism-Screening-ML

Using machine learning to find the fewest AQ-50 questions needed to predict an adult autism diagnosis, compared against the official AQ-10. Our second goal repeats the process on the 80-question RAADS-R and compares it with the official RAADS-14.

CS171 Machine Learning project, Fall 2026, by Ramjot Dhillon and Allyson Wong.

## Data

Panzeri, M., & Vagni, W. D. (2026). *Italian RAADS-R* [Data set]. Centro di Ateneo per le Biblioteche dell'Università degli Studi di Padova. https://doi.org/10.25430/RESEARCHDATA.CAB.UNIPD.IT.00001846

The dataset is licensed under CC BY 4.0. It accompanies the study "Validation and Likelihood-Ratio Calibration of the Italian Ritvo Autism Asperger Diagnostic Scale–Revised (RAADS-R)" by Tortora, Ronconi, Gasparini, Moscone, Panzeri, and Vagni.

The data dictionary is included in data/, but the dataset CSV is not. Download RAADS-R_Italian_validation_dataset.csv from https://researchdata.cab.unipd.it/1846/ and place it in the data/ folder.
